# 弈 · 局域网五子棋

一个**零依赖**的局域网双人对战五子棋：Node.js 后端 + 原生 Web 前端，无需安装任何 npm 包，开箱即玩。

> 把启动后打印的"局域网访问"地址发给同一 WiFi 下的朋友，即可开始一场面对面的五子棋对弈。

## ✨ 功能特性

- **房间制对局**：创建房间生成 4 位房间码，好友输入房间码（或点击邀请链接）即可加入
- **房主执黑先行**：黑白双方实时同步落子，胜负即时判定并高亮五连
- **悔棋协商**：发起悔棋请求，对方同意后回退一手，公平友好
- **认输 / 再来一局**：认输立即判负；双方确认后重开，并**自动交换黑白**
- **对局聊天**：内置实时聊天与快捷短语（"妙啊！""好棋！"……）
- **断线检测**：对手掉线立即通知，并判定在线方为胜者
- **精致 UI**：Canvas 棋盘渲染、落子动画、WebAudio 合成音效（无外部音频资源）、移动端适配
- **零依赖**：不装任何第三方包，WebSocket 协议为手写实现，体积轻、启动快

## 🚀 快速开始

### 环境要求

- Node.js **>= 16**（仅使用内置模块，无需 `npm install`）

### 启动

```bash
node server.js          # 默认端口 3000
node server.js 8080     # 指定端口
```

端口被占用时会自动尝试下一个端口（最多重试 20 次）。

### 开局

1. 启动后控制台会打印访问地址：

   ```
   ┌─────────────────────────────────────────────┐
     五子棋联机服务器已启动
     本机访问:   http://localhost:3000
     局域网访问: http://192.168.1.5:3000  (WLAN)
     把"局域网访问"地址发给同一 WiFi/网段的朋友即可对局
   └─────────────────────────────────────────────┘
   ```

2. 自己打开 `http://localhost:3000`，输入昵称，点击 **⚔️ 创建房间**
3. 把**房间码**或**邀请链接**发给同网段的好友
4. 好友加入后自动开局，执黑先行

> ⚠️ 防火墙提示：首次启动时若 Windows 弹出防火墙提示，请允许 Node.js 在专用网络上通信，否则好友无法连接。

## 🔌 通信协议（WebSocket / JSON）

客户端与服务端通过 JSON 文本消息通信，主要消息类型：

### 客户端 → 服务端

| type | 参数 | 说明 |
|---|---|---|
| `create` | `name` | 创建房间 |
| `join` | `name`, `room` | 加入房间（4 位房间码） |
| `move` | `x`, `y` | 落子（0~14） |
| `chat` | `text` | 发送聊天（最长 200 字） |
| `undo_request` | — | 请求悔棋 |
| `undo_response` | `agree` | 回应悔棋请求 |
| `resign` | — | 认输 |
| `restart` | — | 请求再来一局（双方确认后重开并交换黑白） |
| `ping_ws` | — | 心跳 |

### 服务端 → 客户端

| type | 说明 |
|---|---|
| `created` / `joined` | 创建/加入成功（`joined` 携带 `color`：1=黑 2=白） |
| `start` | 双方就位，对局开始 |
| `move` | 同步落子及下一手回合 |
| `win` | 胜负判定，携带胜利连线坐标 |
| `draw` | 平局（棋盘下满） |
| `undo` / `undo_request` / `undo_result` | 悔棋流程 |
| `resign` | 认输结果 |
| `restart_request` | 对方请求重开 |
| `opponent_left` | 对手离线 |
| `error` | 错误提示（房间不存在、房间已满、未轮到你等） |

## ✅ 运行测试

先启动服务器（默认 3000 端口，或用 `PORT` 环境变量指定），再另开一个终端：

```bash
node server.js
node test/protocol-test.js
```

测试覆盖：WS 握手、建房/加入、交替落子、五连判胜、结束后拒绝落子、聊天、重开交换黑白、悔棋、认输、断线通知。

## 🛠 技术要点

- **手写 WebSocket**：实现了握手（SHA-1 + Sec-WebSocket-Accept）、帧解析（含 126/127 扩展长度与掩码）、消息分片重组、ping/pong、close 处理
- **路径安全**：静态文件服务做路径归一化校验，防目录穿越
- **五连判定**：以新落子为中心，沿横/竖/双斜四个方向扫描连续同色棋子
- **悔棋语义**：若最后一手是自己下的则回退 1 步，否则回退 2 步，保证回退后轮到请求方落子
